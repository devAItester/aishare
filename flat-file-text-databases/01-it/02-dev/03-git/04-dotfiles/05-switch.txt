title: dotfiles synchronization switch
status: draft
date: 2026-10-06
tags: git, dotfiles, sync, config

goal:
  Синхронизировать конфигурационные файлы через Git так, чтобы механизм можно
  было включать и отключать.

requirement:
  local:
    Рабочие файлы остаются на обычных путях.
  repository:
    Версионируются только выбранные конфигурации.
  switch:
    Должна быть явная точка управления синхронизацией.

variants:
  copy:
    Сначала копировать файлы в репозиторий.
  symlink:
    Рабочий файл является ссылкой на файл репозитория.
  script:
    Скрипт выполняет явную синхронизацию.
  bare-repo:
    Git хранит состояние файлов непосредственно в домашнем каталоге.

criterion:
  safety:
    Легко понять, откуда берётся рабочий файл.
  reversibility:
    Можно отключить механизм без потери конфигурации.
  transparency:
    Изменение видно в git diff.
  dependencies:
    Чем меньше вспомогательных программ, тем проще восстановление.

decision:
  current:
    Сначала тестировать варианты на отдельной папке скриншотов.
  reason:
    Эксперимент не должен затрагивать рабочие конфиги.

check:
  before:
    Сделать копию тестового файла.
  after:
    Изменить файл и проверить git status и git diff.
