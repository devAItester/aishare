## Структура

- `pages/` — страницы сайта, сгруппированные по папкам.
- Основная страница папки называется так же, как папка; отдельный `index.md` для каждого раздела не нужен.
- `_includes/folder-navigation.html` — меню, автоматически построенное по папкам и вложенным папкам.
- `_layouts/default.html` — общая HTML-оболочка, подключающая меню.
- `assets/main.css` — оформление.
- `Archive/` — независимое хранилище исходных материалов; сайт от него не зависит.

## Публикация

Сайт использует Jekyll и может публиковаться через GitHub Pages. Включи Pages в **Settings → Pages → Deploy from a branch → main → /(root)**. В _config.yml каталог Archive исключён из результата сборки.

Исходники проверены через GitHub API. Браузерная проверка и проверка опубликованной версии не выполнены; их нужно провести после включения Pages.
