Кратко:
Генератор - это машинерия, которая позволяет программисту контролировать поток выполнения кода, с гарантиями что шаги его исполнения будут исполняться в одном и том же окружении вне зависимости от того, какой шаг генератора (интрепретации потока) сейчас активен.

То есть когда Вы в нормах существующего языка программирования получаете возможность вмешиваться/контролировать каждый логический/семантический шаг исполнения кода.

Генератор - это все множество возможностей языка, которые гарантируют вам тот факт, что базовая единица, подчиненная генератору, будет исполняться всегда и тогда, как на то выписана логика работы генератора программистом где сам программист имеет гарантии относительно того, что внутренние механизмы языка гарантируют ему эквивалентность окружения работы генератора, вне того времени когда его базовая единица будет приведена в состояние исполнения.

То есть основными критериями, делающими генератор особенным механизмом, явдляются реализованные на уровне агента возможности, которые позволяют гарантировать неизменость окружения вне зависимости от того, на каком из шагов находится работа(состояние) генератора.

function findCommonElements(arr1, arr2) {
  const commonElements = [];
  for (let i = 0; i < arr1.length; i++) {
    for (let j = 0; j < arr2.length; j++) {
