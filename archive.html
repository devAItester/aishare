08 / Raw material

The archive is evidence, not the interface.

All files that were present before this curated site were moved under Archive/, retaining their paths relative to the old repository root. This is a preservation boundary, not an endorsement of every note as current or correct.

How to promote material from the archive

  1. Identify the question the material answers.
  2. Check whether it conflicts with a newer decision or another source.
  3. Retain only the evidence and reasoning needed for a durable explanation.
  4. Write or update a curated page and add reciprocal links.
  5. Record any change in the decision register.

The repository is public. Before exposing additional personal notes or machine-specific configuration, review both current files and Git history. Moving files into an archive does not remove them from the repository's history.
