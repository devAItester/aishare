### Key Concepts:
1. Variable Hoisting: In JavaScript, var declarations are hoisted to the top of their function scope. This means that the declaration of a inside the test function is moved to the top of the function, but the assignment remains in place.
2. Scope: var is function-scoped, so the a declared inside the test function is local to that function and does not affect the global a outside the function.

### Step-by-Step Execution:
1. Global a is initialized:
   

   var a = 5;
  

   At this point, the global variable a is set to 5.

2. The test function is called:
   

   test();
  

   When test is executed, the following happens inside the function:
   - The declaration var a is hoisted to the top of the function, creating a local variable a within the function's scope.
   - The assignment a = 10 updates the local a (not the global a).
   - The if (false) block is never executed, so var a = 20 is irrelevant.

   After the function runs, the local a inside test is 10, but this does not affect the global a.

3. console.log(a) is executed:
   

   console.log(a);
  

   This logs the value of the global a, which is still 5.
