undefined - это значение связанное с идентификатором в глобальном обьекте.
В отличии от null который является литералом возвращающим Null type.

то есть если в коде написано null => то Agent вернет вместо null сразу ссылку на null value
если в коде написано undefined => agent осуществит полноценный поиск иднетификатора с именем undefined пока не доберется по цепочке до Global Enviroment где undefied и заявлден.

То есть, когда Вы пишите в коде undefined - то вы на самом деле используете идентификатор, заявленный в Global Ebviroment.
Как следствие, если вы это делаете находясь где то глубоко в коде ( функция в функции в функции) то для полдучение значения undefined нужно провести поиск по всем окружениям.
Например код:
function doThing( theParam ) {
    return theParam === undefined
}

doThing( 1 );

Полностью жквивалентент коду
function doThing( theParam ) {
    return theParam === globalThis["undefined"]
}

doThing( 1 );



Что в случае глубокой вложенности кода - может оказаться накладно.
В этом случае вызов void 0, который возвращает undefined может оказаться быстрее чем поиск по всей цепочке окружений.
Или еще проще - использовать globalThis["undefined"]

Оптимизация с void была долгое время стандартом до появления в спецификации globalThis.
