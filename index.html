A small, connected knowledge site

Build the smallest thing that stays understandable.

These notes turn our work on the David / Oscean reference into a practical system: plain files, explicit links, a stable visual language, and decisions that can be checked rather than guessed.

01 / PURPOSE

What this project is

A text-first site and a repeatable method for copying a reference without losing the reasons behind each choice.

Next: architecture

02 / STRUCTURE

Files before machinery

Keep content readable as files. Use folders to express durable relationships, not to classify every thought.

See also: navigation and backlinks

03 / INTERFACE

The David design language

Quiet typography, restrained color, ordinary links, little decoration, and one shared stylesheet.

See also: publishing checks

04 / METHOD

Decisions, not fragments

Separate verified facts, working hypotheses, accepted choices, and unresolved differences.

Read: source policy

Current direction

  • One external stylesheet at assets/main.css.
  • Static HTML and CSS first; no JavaScript unless a real requirement appears.
  • Every topic points to its prerequisites, consequences, and related decisions.
  • Archive/ preserves previous material; this site is the curated, internally consistent layer.

This is a working instrument, not a claim that every historical detail has been verified. Open the decision register to see what is settled and what remains open.
