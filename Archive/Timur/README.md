# Тимур Шемсединов: архитектурные принципы и паттерны

Эта папка сохраняет исследовательскую выжимку из материалов Тимура Шемсединова и выводы о применении этих принципов к небольшому статическому сайту. Цель — зафиксировать архитектурные границы до того, как проект разрастётся.

## Документы

- [Принципы и идеи из первоисточников](principles.md) — декомпозиция, разделение ответственности, модульность, контракты и контроль зацепления.
- [Применение к «Полевым заметкам»](site-architecture.md) — принятая модель содержимого, шаблона, навигации и сборки.
- [Источники](sources.md) — первичные материалы и границы интерпретации.

## Статус

Документ составлен по доступным первоисточникам 2026-10-09. Это проверяемая реконструкция принципов, а не утверждение, что удалось восстановить дословный список паттернов из прежнего обсуждения. Конкретные паттерны следует применять по задаче, не переносить механически из серверного JavaScript в статический сайт.
