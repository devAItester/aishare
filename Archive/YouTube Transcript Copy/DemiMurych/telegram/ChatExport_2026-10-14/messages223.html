Проблема в тому, що у <link> href веде лише на домен Google Fonts, без самого шрифту. Назва шрифту і ваги мають бути всередині URL у css2?family=… — саме це Gemini щоразу пропускає:

function injectGoogleFont(family, weights = [400, 700]) {
const spec = ${family.replace(/ /g, '+')}:wght@${weights.join(';')};
const href = https://fonts.googleapis.com/css2?family=${spec}&display=swap;
if (document.querySelector(link[href="${href}"])) return;
const sheet = Object.assign(document.createElement('link'), { rel: 'stylesheet', href });
document.head.append(sheet);
}

injectGoogleFont('Roboto', [400, 700]);
document.body.style.fontFamily = "'Roboto', sans-serif"; // підключення ≠ застосування

Три моменти:
1. Назва і ваги — в URL (css2?family=Roboto:wght@400;700), а не голий домен.
2. Пробіли в назві → + (Open Sans → Open+Sans), кілька ваг через ;.
3. Підключення стилю не застосовує шрифт — потрібне ще правило font-family на елементах.

Что это за проект

Headroom — это слой сжатия контекста для LLM/агентов. Уменьшает число токенов (по их
заявлению на 50–90%), сжимая то, что уходит в модель: вывод инструментов, логи,
RAG-чанки, файлы, историю диалога. Python (77%) + Rust (18%) + TS.

Способы использования: библиотека (headroom.compress(...)), прокси (headroom proxy, без
изменений кода), обёртка (headroom wrap claude|codex|cursor|aider), MCP-сервер и плагин
Claude Code. Ключевые модули: SmartCrusher (JSON), CodeCompressor (AST-сжатие кода),
CacheAligner (стабилизация префикса для KV-кэша), CCR (обратимое сжатие с локальным
хранением оригиналов).

Безопасность и утечки

Утечки контента нет. Промпты, файлы, тексты, API-ключи наружу не отправляются — это
подтверждено и чтением кода, и дважды strace (ноль внешних соединений во время
компрессии).

НО есть одно «но» — телеметрия включена по умолчанию. Прокси раз в 5 минут шлёт
анонимную агрегат-статистику в Supabase автора (dtlllcsudcoasebbamcq.supabase.co). В
пейлоаде: сэкономленные токены, % сжатия, hit-rate кэша, версия/ОС/архитектура, список
используемых моделей, и SHA256-хеш имени хоста (стабильный анонимный ID машины).
Содержимое не шлётся. Проверено эмпирически: по умолчанию enabled: True, выключается
HEADROOM_TELEMETRY=off или флагом --no-telemetry (он реально есть в proxy --help).

Что НЕ активно у обычного пользователя (gating в коде):
- app.headroomlabs.ai (биллинг/лицензия) — только если задан платный ключ hlk_....
- Облачные embeddings — память по умолчанию локальная (sentence-transformers/ONNX);
OpenAI только при явной настройке.
- traffic_learner — только с флагом --learn. Langfuse/OTel — только если задать
env-эндпоинты.

Чисто: Rust-ядро прокси шлёт трафик только на ваш сконфигурированный LLM, домой не
звонит. Нет curl|bash, нет вредоносных postinstall-хуков, нет обфускации, ключи не
логируются. Плагин Claude Code запускает лишь локальную команду headroom init hook
ensure.

Замечания:
1. Расхождение в прозрачности: README пишет «runs locally — your data stays here», но
про включённый по умолчанию агрегат-beacon явно не предупреждает.
2. Сборка из исходников тянет нативный ONNX-бинарь со стороннего CDN cdn.pyke.io (крейт
ort-sys) — supply-chain момент. Из-за этого первая сборка в песочнице упала (нет сети),
пересобрал с сетью.
3. ML-сжатие текста (Kompress) при первом использовании качает модель
chopratejas/kompress-base с HuggingFace.

Результат теста

SmartCrusher на JSON-выводе инструмента: 21 797 → 12 687 токенов, экономия 9 110 (~42%),
полностью локально. Он свернул повторяющийся массив в компактную схему + CSV-строки.
Работает как заявлено.

Стоит ли использовать

Да, использовать можно — но с одной обязательной настройкой. Это технически
качественный, активно развивающийся инструмент, и для агентских workflow с большими
tool-output'ами экономия реальная. Вашего контента он не сливает.

Условия безопасного использования:
- Всегда выключайте телеметрию: HEADROOM_TELEMETRY=off (в окружение) или --no-telemetry.
Это критично — по умолчанию метрики о вашем использовании уходят автору.
- Не задавайте лицензионный ключ, если не платите enterprise.
- Память/embeddings держите локальными (это и так дефолт).
- Учитывайте, что полное ML-сжатие обращается к HuggingFace.

Если для вас неприемлема даже анонимная агрегат-статистика «из коробки» — это минус в
карму проекту (privacy-by-default нарушен), но он честно документирован в коде и легко
отключается одним флагом.
