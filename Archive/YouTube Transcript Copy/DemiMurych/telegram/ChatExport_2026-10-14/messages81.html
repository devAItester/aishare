Мурыч часто критикует концепцию, которая распространена на просторах YouTube и звучит примерно так:
*"Объекты передаются по ссылке, а примитивные типы — по значению".*
*Что здесь имеется в виду?*

Пример:

const numbers = [1, 2, 3, 4, 5, 6, 7, 8];

function modifyArray(array) {
    array[0] = 0;
    return array;
}

console.log(modifyArray(numbers)); // [0, 2, 3, 4, 5, 6, 7, 8]
console.log(numbers); // [0, 2, 3, 4, 5, 6, 7, 8]


*Вроде бы функция внутри принимает адрес массива.*

А когда речь идет о "примитивных типах":

let number = 0;

function modify(any) {
    any += 5;
    return any;
}

console.log(modify(number)); // 5
console.log(number); // 0


*Получается, адрес в памяти переменных number и any разный?*

*Я проводил подобный эксперимент в C++, и поведение такое же, если явно не передавать адрес примитива через указатели.*

Рассмотрим поведение массивов:

#include <iostream>
using namespace std;

int numbers[] = {3, 4, 5};

int modifyArray(int array[]) {
    cout << "Address of passed array: " << array << endl; // Address of passed array: 0x404068
    array[0] = 1;
    return array[0];
}

int main() {
    cout << "Address of initial array (numbers): " << numbers << endl; // Address of initial array (numbers): 0x404068
    cout << modifyArray(numbers) << endl; // 1
    cout << numbers[0]; // 1
    
    return 0;
}


*Адрес первоначального массива и адрес массива, переданного в качестве параметра, одинаковы, что означает, что передан просто указатель на исходный массив, и мутация произошла как на локальном, так и на глобальном уровне.*

Теперь если посмотреть на примитивы:

#include <iostream>
using namespace std;

int number = 7;

void printAddresses(int any) {
    cout << &number << endl; // 0x404058
    cout << &any << endl; // 0x7fff3cd9292c
}

int main() {
    cout << &number << endl; // 0x404058
    printAddresses(number);

    return 0;
}


*Видно, что произошло копирование значения в разные области памяти. Как насчет JavaScript? Вроде бы JS ведет себя так же, просто невозможно посмотреть на адреса переменных. Может кто-нибудь разъяснить ситуацию с JS или выложить конкретную статью из спецификации о том, как выглядит модель поведения в JS?*
