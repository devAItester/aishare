• SeqTwoByteString: Same as SeqOneByteString, but uses two bytes for each character. Uses surrogate pairs to represent unicode characters that can’t be represented in two bytes.
• SlicedString: A substring of some other string. Contains a pointer to the parent string and an offset and length.
• ConsString: The result of adding two strings. Contains pointers to both strings.
• ExternalString: Used for strings that have been passed in from outside of V8.
All of these string types inherit from the String class, which has a common header with a pointer to its Map, a hash value, and a length. The size of these fields depends on the system architecture (32-bit or 64-bit).
