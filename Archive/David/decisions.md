# Решения по копии Давида

## Принятые решения

| ID | Решение | Основание | Статус |
|---|---|---|---|
| D-01 | Сохранять стабильные позиции колонок навигации; третий столбец может быть пустым. | Пользователь явно одобрил это отличие от поведения оригинала. | Принято; не отменять при других исправлениях. |
| D-02 | Восстановить повторяющийся halftone-фон на `html`. | В актуальном CSS оригинала есть это правило; пользователь не просил его удалять. | Применено в копии 2026-10-09; нужна браузерная проверка публикации. |
| D-03 | Восстановить `min-height: calc(100vh - 15px)` у body. | Часть оригинальной геометрии, влияющая на видимую область фона html. | Применено 2026-10-09. |
| D-04 | Для целевой Jekyll-архитектуры использовать необязательный локальный `_menu` внутри каталога, когда нужен ручной порядок страниц. Без него — алфавитная сортировка. | Порядок важен, но глобальный реестр дублирует часть структуры; локальный текстовый файл находится рядом с затрагиваемым контентом и не меняет имена страниц. | Принято пользователем 2026-10-09. Подробности и альтернативы — [alternatives/menu-order.md](alternatives/menu-order.md). Перед переносом в конкретную реализацию сверить активный код. |
| D-05 | Для копии использовать один общий внешний CSS-файл, подключённый через `<link rel="stylesheet">`; целевой путь — `assets/main.css`. | Оригинал Oscean использует внешний `links/main.css`. Активный Jekyll layout сейчас вставляет полный CSS через include внутрь каждого HTML, повторяя его на страницах. Внешний файл соответствует оригиналу, упрощает кеширование и не требует усложнения в виде critical CSS. | Решение принято 2026-10-09 после проверки исходников и документации. Реализация в `d00-jk-bc` ещё не выполнена; CSS-декларации при переносе не менять. См. [research/css-architecture.md](research/css-architecture.md). |

## Не приняты как намеренные отличия

| ID | Отличие | Текущая позиция |
|---|---|---|
| P-01 | Grid вместо float header и normal-flow nav | Временный обход сдвига. Проверить возврат к исходной схеме. |
| P-02 | Упрощённый footer | Не одобрено; сравнить HTML и CSS оригинала. |
| P-03 | SVG вместо PNG-логотипа | Не одобрено как визуальное отличие; проверить размеры и поведение. |
| P-04 | Meta color-scheme | Добавлен в нашем шаблоне; проверить влияние. |
| P-05 | Шаблон не выводит пустые списки | Известное отличие; учитывать D-01 при исправлении. |

## Правила

- Наблюдаемое отличие не означает намеренное.
- Временное техническое решение не становится дизайнерским автоматически.
- Не отменять принятые решения при исправлении других отличий.
- Новые выводы и статусы фиксировать в [changes.md](changes.md).
