# Сначала данные, потом представление.

Структура должна оставаться понятной в текстовом редакторе, терминале и на GitHub. Генератор помогает собрать публикацию, но не должен быть единственным местом, где устройство системы имеет смысл.

## Разделение ответственности

| Слой | Где хранится | За что отвечает |
|---|---|---|
| Содержимое страниц | Корневые Markdown-файлы с front matter | Текст, заголовки, метаданные конкретной страницы |
| Данные навигации | <code>_data/navigation.yml</code> | Состав и порядок пунктов основного меню |
| Общий шаблон | <code>_layouts/default.html</code> | Общая HTML-оболочка, заголовок, меню, подвал, подключение CSS |
| Оформление | <code>assets/main.css</code> | Визуальные правила |
| Сборка | Jekyll / GitHub Pages | Преобразование Markdown в HTML |
| Исходный архив | <code>Archive/</code> | Исторические материалы; не является зависимостью сайта |

## Почему не хранить всё в HTML

Когда каждая страница вручную содержит одинаковые меню, заголовки, метаданные и подвал, изменение общего элемента требует редактировать много файлов. Это дублирование создаёт риск расхождений. Общий шаблон хранит повторяемую структуру один раз, а страницы — только собственное содержимое и метаданные.

## Данные и отношения

Содержимое не должно зависеть от оформления. Навигация не должна быть захардкожена отдельно на каждой странице. Связи между темами выражаются явными ссылками в материалах; повторяющиеся глобальные элементы описываются данными и выводятся общим шаблоном.

Пока не нужна отдельная база данных или JavaScript-приложение: Markdown, YAML и статическая сборка покрывают текущие требования. Сложность добавляется только при появлении задачи, которую более простая структура не решает.

## Граница архива

<code>Archive/</code> — соседняя коллекция в репозитории, а не каталог сайта. Она исключена из публикации, не включена в меню, не является источником данных для сборки и может быть перемещена или удалена в будущем без изменения модели страниц. Сайт имеет собственное содержимое и собственную навигацию.
