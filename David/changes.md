# Реестр изменений и отличий

Это единственная таблица для различий между оригиналом Давида и нашей копией. При обнаружении, принятии, исправлении или повторной проверке обновляй строку здесь. Не заводи дублирующие списки без ссылки на этот реестр.

| ID | Область | У Давида | У нас | Классификация | Решение / статус |
|---|---|---|---|---|---|
| C-01 | Фон HTML | Повторяющийся `halftone.gif` на `html`, fixed attachment | Изначально отсутствовал | Случайный пропуск | Восстановлен в `devAItester/d00-jk-bc`; локальный GIF, URL через `relative_url`. Проверить опубликованный результат в браузере. |

| C-03 | Колонки навигации | Соседние `ul`; в оригинале бывает пустой третий `ul` | Три колонки остаются на местах, даже если третья пуста | Намеренное отличие | Пользователь явно одобрил. Сохранять. |
| C-04 | Header/nav | `header { float:left }`, nav в normal flow | CSS Grid | Временное техническое решение | Не считать дизайн-решением; проверить, можно ли вернуть исходную компоновку без сдвига при загрузке логотипа. |
| C-05 | Положение подвала | Подвал находится в обычном потоке документа: длинное содержимое отодвигает его вниз, короткое может оставить его выше нижнего края окна | Подвал прижат к нижнему краю окна на коротких страницах; при длинном содержимом должен идти после текста и не перекрывать его | Намеренное отличие | Сохранить поведение нашей копии. Это сделано специально, чтобы на коротких заметках подвал не оказывался посреди окна. Реализация должна прижимать подвал к низу только при недостатке содержимого, а не фиксировать его поверх страницы. |
| C-06 | Размеры логотипа и сдвиг страницы | Размеры логотипа не заданы явно в HTML-разметке, поэтому при загрузке изображения может изменяться геометрия страницы | Для логотипа заданы жёсткие размеры, чтобы заранее резервировать место; таблица не должна съезжать при загрузке | Исправление компоновки | Сохранить заданные размеры и проверить результат на опубликованной странице. Это отдельная проблема от выбора формата PNG/SVG. |
| C-07 | Color scheme | В проверенном исходном шаблоне нет соответствующего meta-тега | Добавлен `meta name="color-scheme" content="light dark"` | Нерешённое расхождение | Проверить влияние; не считать необходимым без основания. |
| C-08 | История CSS | Halftone отсутствует в снимке 2023 и версии до изменения в 2024; присутствует после коммита 2024-09-02 | Скопировали CSS без текстуры | Причина установлена | Ошибка процесса: не сравнили весь актуальный CSS как обязательный шаг. |

Отдельная задача на будущее — изучить рекомендации по подготовке SVG и выбору его размеров; значение 200×42 не считать обоснованным стандартом без проверки. |
