02 / Структура

Обычные файлы — источник истины.

Структура должна оставаться понятной в текстовом редакторе, терминале и на GitHub. Генератор может помогать с публикацией, но не должен становиться единственным местом, где устройство системы имеет смысл.

Три отдельных слоя

Исходные материалы
Оригинальные страницы, сохранённые CSS-файлы, референсы и исследовательские данные. Сохраняй происхождение материалов и не переписывай их так, будто это наши выводы.
Отобранные знания
Короткие поддерживаемые страницы с ясной целью, явными ссылками и известным статусом. Именно этот слой читает человек.
Опубликованный результат
Статические HTML и CSS, которые браузер может обслуживать напрямую. Сгенерированный результат должен поддаваться проверке, а содержимое не должно зависеть от клиентского JavaScript.

Информационная архитектура — это не только каталоги

Каталог задаёт физический адрес, а ссылки выражают смысловые связи. Страница о CSS может находиться в разделе реализации, но ей также следует ссылаться на исходный референс, выбранный способ подключения стилей и процедуру проверки. Поэтому обратные и связанные ссылки — часть модели содержимого, а не украшение.

Выбор генератора

Oscean — не обычный проект на Jekyll: в оригинальном репозитории он описан как статическая вики, генерируемая из обычного текстового содержимого с помощью Uxntal. Jekyll может быть слоем публикации нашей копии, но это не эквивалент исходной архитектуры. Собственный генератор стоит рассматривать только в том случае, если ограничения текущих инструментов оправдывают расходы на его поддержку.

Практические ограничения

  • Предпочитать устойчивые, читаемые человеком имена файлов и URL.
  • Хранить общую таблицу стилей отдельно от HTML-документов.
  • Не добавлять JavaScript для содержимого, которое можно выразить статическим HTML.
  • Делать главную страницу полезной картой, а не копией всех страниц подряд.
Связанные заметки
  • Общий CSS и визуальный язык
  • Проверки сборки и публикации
  • Решение о внешней таблице стилей
  • Исходные файлы Oscean в архиве
