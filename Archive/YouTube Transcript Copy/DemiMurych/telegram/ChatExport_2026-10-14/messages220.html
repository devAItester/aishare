🔍 Модуль v8 — доступ к движку вашего приложения

Node.js выполняет JavaScript-код с помощью движка V8 от Google. Встроенный модуль v8 предоставляет прямой доступ к внутренним механизмам этого движка. С его помощью можно проводить глубокий аудит памяти, настраивать сборщик мусора (Garbage Collector) и сериализовать данные на максимальной скорости.

v8 — управление памятью и системные дампы

— getHeapStatistics()
— serialize() / deserialize()
— writeHeapSnapshot()
— setFlagsFromString()

— getHeapStatistics() — возвращает детальную статистику о куче (heap) — области памяти, где хранятся все ваши объекты. Помогает вовремя заметить утечки памяти (memory leaks) до того, как приложение упадет с ошибкой JavaScript heap out of memory.

const v8 = require('v8');
const stats = v8.getHeapStatistics();

console.log(`Доступный лимит памяти: ${(stats.heap_size_limit / 1024 / 1024).toFixed(2)} MB`);
console.log(`Использовано памяти: ${(stats.used_heap_size / 1024 / 1024).toFixed(2)} MB`);


— Сериализация (serialize / deserialize) — встроенные методы для сверхбыстрого копирования и передачи объектов. Они работают в разы быстрее, чем связка JSON.parse(JSON.stringify(obj)), и при этом поддерживают специфические типы данных вроде Map, Set, RegExp и BigInt.

const data = { map: new Map([['key', 'value']]), date: new Date() };

const buffer = v8.serialize(data); // Превращает в бинарный буфер V8
const clone = v8.deserialize(buffer); // Восстанавливает объект со всеми типами



— writeHeapSnapshot() — делает снимок всей памяти приложения и сохраняет его в файл. Этот файл можно загрузить в Chrome DevTools во вкладку "Memory", чтобы детально изучить, какие именно объекты занимают место в системе.

— setFlagsFromString() — позволяет менять настройки самого движка V8 прямо во время выполнения кода. Например, так можно принудительно изменить поведение оптимизатора или включить экспериментальные функции.
