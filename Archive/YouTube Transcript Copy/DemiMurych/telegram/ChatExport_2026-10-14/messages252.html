Черешня Сладкая

{

<article>Черешня
  <article>Сладкая</article>

{
"body": {
    "Черешня" : {
       "Сладкая": {
       }

}
}


сравнение с JSON тут очень условно, чтобы почеркнуть важность того или иного тега

article - значит все что внутри может быть вырвано из старницы, и как контент который можно показать отдельно. Ничего для него не сломается. Не в техническом смысле не сломается, но в смысловом.

section - означает выделение значимой части из article которая стоит отдельного заголовка и специальных уточнений. Который вырвать из контекста нельзя.

nav - секция заявляющая механизмы навигации по контенту

aside - сообщает о контенте который не должен быть связан с текущей иерархией секций.
