# Меню определяется папками

Основное меню не требует ручного списка, категорий или тегов. Его источником служат пути Markdown-страниц внутри `pages/`.

## Правила

- **Папка** — пункт меню.
- **Вложенная папка** — вложенный пункт меню.
- **Главная страница папки** — файл с именем папки, например `pages/03-navigation/03-navigation.md`. Файлы `index.md` для разделов не нужны.
- **Название пункта** — `title` основной страницы папки.
- **Адрес пункта** — `permalink` основной страницы; URL не выводится из имени каталога.
- **Остальные страницы** — обычные страницы в этой папке; они не дублируются ради навигации.
- **Корневая главная** — `pages/index.md`, отдельная страница сайта, не индекс раздела.

Шаблон `_includes/folder-navigation.html` обходит `site.pages`, выделяет каталоги и рекурсивно формирует меню. `_layouts/default.html` только включает этот шаблон в существующую оболочку. Отдельный `_data/navigation.yml` больше не нужен.

## Почему у папки есть основная страница

Сам каталог не имеет собственного `permalink`: URL назначается странице. Поэтому принято файловое соглашение: основная страница именуется как папка, а её front matter содержит желаемый публичный URL. Если одноимённого файла нет, папка не получает пункт меню. Шаблон не выбирает произвольную страницу вместо главной.

Категории и теги не участвуют в основном меню. Их можно добавить позднее для сквозных тематических списков, не меняя папочную навигацию.

## Обратные ссылки и карта сайта

Для небольшого сайта достаточно явных ссылок между важными материалами. Позже можно автоматически строить отчёт об обратных ссылках из исходников — как производную проверку, а не отдельную вручную поддерживаемую базу отношений.

[Карта сайта](map.html) показывает страницы, входящие в публикацию. Каталог `Archive/` остаётся независимым архивом: он не участвует в меню и не является источником страниц сайта.
