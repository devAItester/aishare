03 / Relationships

Links carry the meaning folders cannot.

A useful knowledge site is a graph. Pages are nodes; ordinary links make their relationships explicit and durable.

Minimum link contract

  • Every page links back to the home page.
  • Every topic names its prerequisites and related decisions.
  • Every important conclusion links to evidence or a test.
  • Indexes link forward into topics; topics link back to their index or parent.
  • Links use descriptive words, not “here” or an unexplained filename.

Backlinks without a database

For a small static site, explicit reciprocal links are often enough. If page A links to page B because B supports a decision, B should usually link back to A in a “used by” or “related decisions” section. A generator can automate link reports later, but the relationship itself should remain understandable in plain text.

Navigation is not a dump of all files

The main navigation should expose stable top-level concepts. A local index can order related pages when sequence matters. Alphabetical order is a reasonable default; manual order should be an explicit exception, not hidden in fragile template logic.

Check links as part of publishing

Validate internal destinations after moving or renaming files, then inspect the deployed site. A source link can look correct while the published URL is wrong because of case, extension, or base-path rules. See the publication checklist.
