1) Если мы говорим о коде, который должен отвечать своременной спецификации async awaite - то есть повторять ее - то он упрощен.

То есть чтобы ее повторить нужно добавить еще несколько граничных условий.

В синтаксисе async/await всех в спервую очердь волнует возможность выполнять асинхронный код, последовательно.

Вас не волнуют пограничные случаи.

Тут нужно сделать важное отдельное пояснение.

Никакого empty в рамках спецификации ECMA - НЕТ.

Термин empty возникает в рамках того что пишет devtools.

И означает он следующее:
Если в диапазоне значений, верхняя граница которых определяется значением length, при проверки наличия каждого конретного ключа ИМЕННО в этом обьекте, такого ключа не обнаруживается - то devtools пишет empty.

undefined - это конкретное значение. Это не абстракция которая говорит о том что чего то нет.

Точно так же и null - это конкретное значение.

Чтобы стало яснее нужно посмотреть на примеры:

var theArr = Array(1);

Этот код создает Exotic Object Array, у которого property length установлено в значение 1.

БОЛЬШЕ НИЧЕГО НЕ ДЕЛАЕТСЯ

как следствие, при попытке вывести в консоль theArr мы увидим что-то подобное 
console.log( theArr );
// [empty]


если мы изменим length своими руками:
theArr.length = 10;
console.log( theArr );
// [empty × 10]


что говорит о том, что ВСЕГО 10 элементов (.length) в рамках Exotic Object Array должны юыть последовательно использованы, НО
каждый из них ( theArr[0] ... ) на самом деле не имеет реального ключа в обьекте.

Как следствие - devTools пишет про empty.

То есть empty - это не какой то особый тип. Это всего лишь обозначение в рамках devtools для Exotic Object Array ситуации с ключами которые не установлены для диапазона от 0 до значения из length

var theArr = Array(1);
theArr.length = 10;
console.log ( theArr );
// (10) [empty × 10]
theArr[3] = 1;
console.log( theArr );
// (10) [empty × 3, 1, empty × 6]
theArr[3] = undefined
console.log( theArr );
// (10) [empty × 3, undefined, empty × 6]
delete theArr[3]
console.log( theArr );
// (10) [empty × 10]
