# Folder naming

For every new directory name we invent, use lowercase English ASCII letters and hyphens between words. Digits are allowed where useful.

- Use `lowercase-english-words`.
- Do not use spaces, underscores, CamelCase, uppercase letters, or Cyrillic in newly created directory names.
- Keep names short and descriptive; prefer stable, readable slugs over full titles.
- Preserve case-sensitive identifiers assigned by external systems as data (for example, YouTube video IDs) in metadata or filenames; do not alter the identifier itself to fit a directory-name convention.
- Do not rename imported/exported source directories automatically. Apply this rule to new directories we create, and migrate existing directories only as a separate, deliberate change.
