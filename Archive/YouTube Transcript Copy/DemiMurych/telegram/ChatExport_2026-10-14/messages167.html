- Coerce the receiver to a string (if it isn’t already).
- Convert the argument to an integer (using ToIntegerOrInfinity).
- Handle negative indices: If the index is negative, it counts from the end (str.length + index).
- Bounds check: If the resulting index is out of bounds, return undefined.
- Return the code unit at the index (not a full Unicode code point for surrogate pairs).

typescriptString.prototype.at = function(index: number): string | undefined {
  const str = String(this);
  const len = str.length;
  let relativeIndex = Number(index);

  if (Number.isNaN(relativeIndex)) relativeIndex = 0;
  if (relativeIndex < 0) relativeIndex += len;

  if (relativeIndex < 0 || relativeIndex >= len) return undefined;

  return str.charAt(relativeIndex);
};


Key points:

- Negative indices are supported.
- Returns a single UTF-16 code unit (not a full Unicode character if surrogate pairs are involved).
- Returns undefined if out of bounds.

Наиболее полный ответ:

Согласно спецификации, код: 
{} + [];

разбивается на два разных Statement:
1) 
 {}

 - Block Statement. За которым автоматически ставится точка с запятой


2) 
 +[];

Unary + Operator применяемый к Exotic Object Array.

Как следствие, на результат влияет только второй Statement, назначение которого приведение к числу той части, которая идет следом за +.
Которая, в случае Exotic Object Array вернет 0, при условии если стандартный метод valueOf и/или метод Symbol.toPrimitive остались по умолчанию, а сам Array не содержит элементов.



В то же время второй код:
[] + {}; // [Object object]

Является одним полноценным выражением The Addition Operator. Выполняя которое, левая и правая часть должна быть приведена к Primitive Value без указания Preferred Type. А в этом случае приведение должно происходить с указанием Preferred Type NUMBER. Это не тип Number - это один из двух (STRING или NUMBER) алгоритмов преобразования Object, который приводит к соотвествующему типу если это возможно. Или любому другому типу, предусмотренному выбранным алгоритмом.

Поскольку у наших Regular Object и Exotic Object Array метод Symbol.toPrimitive не переопределен, то мы оказываемся в стандартном OrdinaryToPrimitive, для алгоритма NUMBER, где определена последовательность шагов:
Вызвать valueOf.
Результат is not an Object?
Если да вернуть его
Если нет Вывзвать toString
Результат is not an Object?
Если да вернуть его
Если нет throw Error

стандартный valueOf для Object и Array возвращают сами себя - то есть тип Object. А значит вызывается toString.
Который в случае empty array возвращает empty string, а в случае Object строку '[Object object]'

После чего мы возвращаемся в оригинальную ветку The Additional Operator, где, как мы наверняка знаем, в случае использования оператора + и если хотябы один из аргументов является Primitive Value String, выполняется конкатенация двух строк
