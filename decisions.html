06 / Decision register

Decisions must be traceable.

This is the current curated record. Historical notes in the archive may contain earlier ideas or conflicting wording; this page defines the present direction unless marked otherwise.

D-01 · ACCEPTED

Use one shared external stylesheet.

Publish the design through assets/main.css and link it from each HTML page. Do not embed the complete stylesheet into every page. During a migration, move the existing declarations without mixing in unrelated redesigns.

Reason: the reference uses an external stylesheet; this keeps one source of truth and permits the browser to cache the file independently.

Related: visual language · architecture · verification

D-02 · ACCEPTED PRINCIPLE

Keep the archive separate from the reading site.

Preserve old material under Archive/. Curated pages may rewrite, consolidate, or reject the material, but must not silently overwrite its historical record.

Related: project purpose · archive map · evidence policy

D-03 · ACCEPTED PRINCIPLE

Use static HTML and CSS as the baseline.

Do not add a client-side framework or JavaScript merely to render pages or navigate between them. Revisit the constraint only when a concrete requirement cannot be met simply.

Related: architecture · navigation

D-04 · OPEN

Choose the long-term content generator.

The reference uses its own Uxntal-based generation flow. Jekyll and a small custom generator have been discussed as alternatives; neither should be described as the original implementation. The choice depends on how much structure and navigation we need to generate automatically.

Related: architecture · preserved implementation research

D-05 · OPEN

Automate link and publication checks when justified.

Explicit reciprocal links are sufficient for the first version. A link checker can be added when page count makes manual review unreliable; it should report problems rather than hide the source structure.

Related: link model · publication checks

This register describes the new Field Notes site. It does not retroactively claim that these decisions were already implemented in the separate Jekyll copy.
