# Поиск по транскриптам

## Индекс

`transcript-index.json` содержит пути, размеры и Git blob SHA для всех файлов `.vtt` в `Archive/YouTube Transcript Copy/DemiMurych/full/` на ветке `main`. SHA позволяет определять, изменился ли конкретный транскрипт. Это индекс метаданных, не полнотекстовый индекс.

## Повторный поиск

1. Читать `transcript-index.json`, а не перечислять каталог заново.
2. Сначала отбирать файлы по дате, названию и языку (`ru.vtt` предпочтительнее `ru-orig.vtt`).
3. Получать текст через GitHub blob API по сохранённому SHA.
4. Искать по вариантам формулировок и вероятным ошибкам распознавания субтитров.
5. Для совпадения извлекать несколько минут контекста вокруг таймкода; совпадение отдельного слова не считать подтверждением.
6. При обновлении индекса сравнивать путь и SHA с текущим Git tree; повторно читать только новые/изменённые blobs.

## Поиск «фальшивая корпоративная этика / все улыбаются, но плохо работают» — 2026-10-21

Поиск ограничен транскриптами около 2023-12-01 и ключевыми словами о корпоративной культуре, улыбках, коллегах, лицемерии и отношении к работе. Точного совпадения пока не подтверждено.

Ближайший по смыслу найденный фрагмент:

- Видео: **⎡coding：12-3⎦ LeetCode：30 JavaScript задач за 30 часов — Part 3**
- Дата в архиве: `2023-11-25`
- YouTube: https://www.youtube.com/watch?v=_su4lhLXwfk
- Таймкод: **04:44:45–04:45:09**
- Контекст транскрипта: «…я прихожу на работу… я иногда приезжаю… со своими коллегами общаюсь, а им настолько плевать там на оптимизации…» Далее обсуждается, что многим людям в профессии не очень интересны глубокие технические вопросы.
- Blob SHA: `0e0e7c7b8f28a188457f3a0525cba45469dabeb1`

Это тематически близкий эпизод о безразличии коллег к качеству/оптимизации, но **не подтверждён как искомый эпизод про фальшивую корпоративную вежливость**.

Ещё одна проверенная зацепка — видео **⎡talks：11⎦ Награждение AsForJS плюс ответы на вопросы** (`2023-12-04`), около **04:10:10**; там речь о коллегах, которые занимаются своими делами, но найденный контекст не совпадает с описанием достаточно точно.

При продолжении поиска сначала проверить соседние выпуски конца ноября — начала декабря 2023 года, затем расширить диапазон. Не выдавать похожий эпизод за точное совпадение без подтверждающего контекста.
