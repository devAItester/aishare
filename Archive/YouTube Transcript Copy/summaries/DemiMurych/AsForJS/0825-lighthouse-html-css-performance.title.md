# Как LightHouse оценивает ваш HTML и CSS с точки зрения производительности

**title:** Разбор стороннего dropdown-меню, заявленного как высокопроизводительное решение без библиотек, с помощью Chrome DevTools и Lighthouse. На конкретном коде проверяются внешние запросы, загрузка CSS и шрифтов, иконки и SVG, лишние DOM-узлы, Core Web Vitals и особенно CLS. Выпуск показывает, как локализовать причину плохой метрики и почему высокий итоговый балл ещё не означает, что страница действительно стала лучше.
