# Источники по архитектурным принципам Тимура Шемсединова

## Основные источники

- [Patterns 2024 — русский текст в HowProgrammingWorks/Index](https://github.com/HowProgrammingWorks/Index/blob/master/Courses/Patterns-2024-ru.md) — модульность, DI/IoC, декомпозиция абстракций, GRASP, GoF, SoC, SOLID, контрактное моделирование и Clean/Layered Architecture.
- [Patterns-JavaScript — репозиторий Тимура Шемсединова](https://github.com/tshemsedinov/Patterns-JavaScript/tree/ru) — каталог паттернов с примерами для JavaScript/TypeScript.
- [HowProgrammingWorks/Principles](https://github.com/HowProgrammingWorks/Principles) — каталог общих принципов программирования.

## Ограничения

Эти источники обосновывают принципы, но не подтверждают, что каждая рекомендация для данного сайта является дословным предписанием автора. Применение к статическому сайту — наша инженерная интерпретация. Названия паттернов, принципы и конкретные решения следует различать.
