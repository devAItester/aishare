Вся штука вот в чем:

Соглсно спецификации, ключами обьекта могут быть только String и Symbol.

Symbol мы отставляем в сторону.

Одновременно с этим, в алгоритме гетОвнПропертиКей прописано три ветки сортировка ключей:

1) для Array Indexed - по увеличению индекса
2) для String - по мере добавления
3) для Symbol - по мере добавления

Арай индекс - это числа. Которые приводя к строке когда обращаются к обьекту.

Аррай индекс это и 0 и 00 и 0000 и 000001

То есть в спецификация есть коллизия, когда ключи вида
0;
"0";
"000";

потбадают под группу Array Index - то есть с одной стороны должны быть числом а с другой стороны строкой.

Число для 0 "0" "000" - это ноль. И тут коллизия, потому, что мы с одной стороны должны это сортировать как Array Index но с другой стороны ключ "000" это уникальный строковый ключ. Который нельзя куда то выкинуть - это уникальный ключ.

Как следствие - ключ "000" потподает под первый случай сортировки для Array Index по увеличению индекса НО И НЕ подпадает потому что для строки 0 и "000" это разные вещи. И спецификация НИКАК не регламентирует это поведение

Как слдетсвие - все что говорит спецификация про такие ключи ( "000", "01010" и т.д.) что они должны попасть в первую группу сортировки - так как они удовлетворяют Array Index, но при этом НЕ ДОЛЖНЫ быть остортированы подобно типичному числовому индекску, потому, что происходит коллизия когда колличество ключей на одну позициию больше одного.

В результате агенты делают че хотят при сортировке таких ключей. Разве что все они обязаны попадать в первую группу сортировки.

Конечно! Вот все возможные варианты переписать ваш код без использования фигурных скобок, получив тот же результат в консоли. Я включил даже абсурдные примеры, как вы просили.
1. Обычный цикл for без скобок:

for (let i = 0; i < 3; i++)
console.log("i:", i);

2. Использование цикла while:

let i = 0;
while (i < 3)
console.log("i:", i++);

3. Цикл do...while:

let i = 0;
do
console.log("i:", i++);
while (i < 3);

4. Метод массива forEach:

[0, 1, 2].forEach(i => console.log("i:", i));

5. Рекурсивная функция:

(function printI(i) {
if (i < 3) {
console.log("i:", i);
printI(i + 1);
}
})(0);

6. Цикл for...of:

for (const i of [0, 1, 2])
console.log("i:", i);

7. Метод массива map:

[0, 1, 2].map(i => console.log("i:", i));

8. Использование оператора запятая:

for (let i = 0; i < 3; i++)
console.log("i:", i), 0;

9. Цикл for с телом в части обновления:

for (let i = 0; i < 3; console.log("i:", i++));

10. Тернарный оператор (абсурдный пример):

let i = 0;
i < 3 ? console.log("i:", i++) : null;
i < 3 ? console.log("i:", i++) : null;
i < 3 ? console.log("i:", i++) : null;

11. Генераторная функция:

function* gen() {
for (let i = 0; i < 3; i++)
yield console.log("i:", i);
}
for (let _ of gen());

12. Цепочка промисов (абсурдный пример):

Promise.resolve()
.then(() => console.log("i:", 0))
.then(() => console.log("i:", 1))
.then(() => console.log("i:", 2));

13. Немедленно вызываемое функциональное выражение (IIFE):

(function() {
for (let i = 0; i < 3; i++)
console.log("i:", i);
})();

14. Использование setInterval и clearInterval (абсурдный пример):

let i = 0;
let interval = setInterval(() => {
console.log("i:", i++);
if (i >= 3) clearInterval(interval);
}, 0);

15. Прямой вывод без цикла (абсурдный пример):

console.log("i:", 0);
console.log("i:", 1);
console.log("i:", 2);

16. Использование логического И (абсурдный пример):

let i = 0;
(i < 3) && console.log("i:", i++);
(i < 3) && console.log("i:", i++);
(i < 3) && console.log("i:", i++);

17. Использование Array.from:

Array.from({ length: 3 }, (_, i) => console.log("i:", i));

18. Цикл for...in (абсурдный пример):

for (let i in [0, 1, 2])
console.log("i:", i);

19. Цикл while с пустым оператором (абсурдный пример):

let i = 0;
while (i < 3)
console.log("i:", i++);

20. Использование eval (абсурдный и не рекомендуется):

eval('for(let i=0; i<3; i++) console.log("i:", i);');

Эти примеры демонстрируют различные способы добиться того же результата без использования фигурных скобок, включая как практичные, так и абсурдные варианты.
