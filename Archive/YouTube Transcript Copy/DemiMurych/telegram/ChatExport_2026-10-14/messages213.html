может стоит чаще общаться с LLM-ками?
В JS: var — действительно устаревший по стилю, но не «deprecated» в спецификации; он создаёт переменную в объектной среде выполнения (Object Environment Record) при глобальной декларации и в VariableEnvironment (не в LexicalEnvironment) для функций/скриптов. Ключевые моменты:

Поднятие (hoisting): объявления var поднимаются в начало своей функции или глобальной области; инициализация значением undefined происходит до выполнения кода.
Область видимости: функциональная (function-scoped). Внутри блоков (if, for) var не создаёт новую область.
Глобальные var создают свойства глобального объекта (window в браузере): var a = 1; → window.a === 1.
Повторные объявления: допустимы и игнорируются (не бросают ошибку).
TDZ: для var нет Temporal Dead Zone — переменная доступна до выполнения, но равна undefined.
Hoisting vs. initialization: объявление hoisted, присвоение остаётся на месте выполнения.
Безопасность/лучшие практики: предпочитайте let/const (block-scoped, нет нежелательного hoisting/глобальных свойств, const для неизменяемых привязок).

Кратко о «Object Environment Record» vs «VariableEnvironment»:

При глобальной декларации движок создаёт Object Environment Record, связанный с глобальным объектом; var объявление регистрируется как свойство этого объекта.
Внутри функции var отслеживается через VariableEnvironment (специфическую запись переменных), а не через LexicalEnvironment, что даёт функциональную область видимости и подъем.
