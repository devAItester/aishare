04 / Interface

Quiet design, clear structure.

The reference's strength is not a collection of effects. It is a restrained visual system in which text, spacing, and links do most of the work.

Design rules

  • Use a narrow reading measure and a clear typographic hierarchy.
  • Keep the palette restrained; links should remain recognisable as links.
  • Prefer text labels to decorative icons when the label is clearer.
  • Use spacing and rules to separate sections instead of cards everywhere.
  • Preserve useful browser defaults and semantic HTML.
  • Keep the stylesheet shared and external at assets/main.css.

External, embedded, and inline CSS

These are different delivery mechanisms. A <link rel="stylesheet"> references an external file; <style> embeds a stylesheet in a document; a style attribute applies declarations to one element. The original Oscean uses a shared external file. Embedding the whole stylesheet in every page repeats bytes and prevents independent caching of that stylesheet.

The decision is to use one external file without changing the CSS declarations during the first migration. Critical CSS is not justified until a measured rendering problem exists. The technical background is in decision D-01 and the preserved CSS research.

Copy first; redesign separately

When fidelity is the goal, compare all selectors, declarations, media queries, assets, and URL paths before polishing individual details. A visual resemblance alone does not prove that layout behaviour is equivalent. Record intentional deviations separately from accidental ones.
